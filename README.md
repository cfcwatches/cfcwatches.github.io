# CFC Watches — Premium Garmin Watch Faces

CFC Watches is a collection of premium analog and digital watch faces designed for Garmin devices.  
Each watch face is built with a focus on clean geometry, high‑contrast clarity, and practical on‑device customization.  
The project showcases modern analog styling, bold digital layouts, and refined theme systems that work consistently across Garmin AMOLED and MIP screens.

This repository hosts the public webpage for CFC Watches, including feature overviews, screenshots, and direct links to each watch face on the Garmin Connect IQ Store.

---

## Watch Faces Included

### **Crownline Analog**
A modern analog watch face featuring handcrafted numerals, multiple bezel styles, premium hand options, and customizable complications. Designed with center‑aligned geometry for crisp rendering across all supported devices.

### **FiveTone**
A clean digital layout built around a large, easy‑to‑read time display and five bold colour themes. Time and date appear on the left, with configurable daily metrics on the right.

### **Halo Glow**
A bold digital watch face with a bright central glow and ten vibrant themes. Includes eight configurable data fields and full on‑device customization.

### **FlipDeck**
A modern flip‑clock design blending classic digital cards with contemporary clarity. Supports custom messages and multiple curated themes.

### **Progress Halo**
A high‑contrast digital layout featuring three customizable progress rings, weather, heart rate, battery, and daily totals. Built for smooth performance on both AMOLED and MIP devices.

### **Quadrant Prime**
A hybrid analog–digital watch face with four data quadrants, sunrise/sunset awareness, and eight curated themes. Fully customizable directly on the watch.
